# Version a0.14.1 - Enhanced Quest System & Item Integration

## 🚀 Features Added
- **Enhanced Quest Status System**: Replaced "Ready" with "Available" quests for better user clarity
- **Quest Tagging & Search**: Added clickable tag filters and search functionality for quests
- **Item Rarity System**: Implemented color-coded item rarities (common=white, uncommon=green, rare=blue, epic=purple, legendary=orange)
- **Integrated Item Display**: Quest rewards now show proper item names from items.json instead of raw IDs
- **Enhanced Rumors System**: Added tags and structured content to rumors for better organization
- **Developer Quest Tools**: Added comprehensive quest management commands for testing

## 🔧 Improvements
- **Item Integration**: Items.json data now properly integrates with quest rewards display
- **Inventory System**: Fixed inventory to show actual player items with proper categorization and rarity colors
- **Data Manager**: Enhanced to handle flat item structure correctly
- **Quest Filtering**: Added support for multiple quest categories (Active, Available, Completed) 
- **Save/Load System**: Fixed quest manager integration with game persistence

## 🐛 Critical Fixes
- **File Corruption**: Completely fixed corrupted game.js file structure and resolved all syntax errors
- **Duplicate Functions**: Removed duplicate function definitions causing runtime errors
- **Quest Manager**: Fixed initialization and data persistence issues
- **Item Lookup**: Corrected item retrieval to work with current JSON structure
- **Class Structure**: Properly closed GameEngine class and fixed method accessibility

## 📊 Data Updates
- **New Items**: Added cursed_amulet, ancient_tome, treasure_map, gold_coins to items.json
- **Item Enhancement**: Added proper rarity and description fields to all items
- **Rumors Enhancement**: Updated rumors.json with tags and enhanced content structure  
- **Quest Validation**: Ensured all quest rewards reference valid item IDs

## 🔧 Technical Details
- Fixed GameEngine class structure and method organization
- Added proper global function wrappers for HTML callbacks
- Enhanced data manager item retrieval with fallback support
- Implemented quest filtering and search framework
- Added comprehensive error handling for quest operations

## 🎯 Impact
This update significantly improves the quest and inventory experience by:
- Making quest management more intuitive with clear status labels
- Providing visual feedback through item rarity colors
- Enabling better quest organization through tags and search
- Ensuring data consistency between quest rewards and item definitions
- Stabilizing the overall game architecture
